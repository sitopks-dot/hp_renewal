# SITOP — Web renewal concept

スクロール連動の3D機器分解を中心にした、日本語のWebサイト・プロトタイプです。Vite + Three.js を使用しています。

## 開発

Node.js 22.12以上（この環境では24.19）、npmを使用します。

```sh
cd /workspace/hp_renewal
npm ci
npm run dev -- --port 5173
```

## 検証

```sh
npm run build
npx playwright test
```

ブラウザテストはこの環境の `/usr/bin/chromium` を利用します。開発サーバー起動中に実行してください。PC表示、スクロールによる機器切替、問い合わせダイアログ、スマートフォンの横幅、動きを減らす設定を確認します。

## 公開前の確認

- 既存サイトはこの環境からHTTP 403となったため、既存文章・正式ロゴは未移植です。事業紹介とコピーは提案用です。
- 問い合わせは送信フォームではなく、現公式サイトへの案内です。
- 正式な事業内容、会社概要、問い合わせ先、プライバシーポリシー、ロゴを確認して反映してください。
- Google Fontsが取得できない環境ではシステムフォントで表示されます。
- WebGL非対応時は静止背景に切り替わります。アニメーション用動画のダウンロードはありません。

参考動画はデザイン参考としてのみ確認しており、サイト配信ファイルには含めていません。
